InspectMap · 모델 좌표계 3D 손상 JSON

외관망도 작성기의 전체 3D 손상 JSON 버튼은 현재 데이터 세트의 활성 투영 결과를 한 파일로 저장합니다. 형식 식별자는 inspectmap.model_damage.v1입니다.

포함 기준

모델 표면에 투영이 완료되고 3D 경로가 있는 손상만 damages에 들어갑니다. 투영 검토에서 제외하거나 보류한 손상, 투영이 불완전한 손상은 생략하고 건수를 omitted에 기록합니다. 동일 손상 묶음은 대표 1건, 이어진 손상은 원래 선들을 유지한 대표 1건으로 나옵니다.

주요 필드

필드의미
coordinate_system좌표계 MODEL, 축 순서 x,y,z, 좌표 단위 m. 지리 좌표계나 GeoJSON 좌표가 아닙니다.
source점검, 데이터 세트, 투영 실행 및 정합 결과 ID. 어느 결과에서 생성됐는지 추적할 때 사용합니다.
damage_count, omitted출력된 손상 수와 제외·보류·투영 미완료 건수.
damages[].geometry.paths_xyz각 경로는 [[x,y,z], ...] 형식입니다. 여러 선이나 경계 경로를 담을 수 있으며, 서로 떨어진 경로 사이가 연결됐다는 뜻은 아닙니다.
damages[].measurements3D 투영 외접 폭·길이는 m, 균열 두께 p90은 mm입니다. 계산할 수 없는 값은 null입니다.
damages[].source대표 손상에 연결된 원본 객체 ID와 영상 이름. 묶음이 없으면 원본 1건이 들어갑니다.

예시

{
  "schema": "inspectmap.model_damage.v1",
  "generated_at_utc": "2026-11-27T09:00:00.000Z",
  "coordinate_system": {"frame": "MODEL", "unit": "m", "axes": ["x", "y", "z"]},
  "source": {
    "inspection_id": "inspection-1",
    "dataset_id": "dataset-1",
    "projection_run_id": "run-1",
    "registration_id": "registration-1"
  },
  "damage_count": 1,
  "omitted": {"excluded": 0, "deferred": 0, "unprojected": 0},
  "damages": [{
    "damage_id": "damage-1",
    "type": "crack",
    "part_id": "part-1",
    "face_id": "face-1",
    "geometry": {"type": "MultiPath3D", "paths_xyz": [[[1.0, 2.0, 3.0], [1.2, 2.1, 3.0]]]},
    "measurements": {"bbox_width_m": 0.4, "bbox_length_m": 4.0, "crack_width_p90_mm": 0.3},
    "source": {"group_id": null, "group_kind": null,
               "object_ids": ["damage-1"], "image_names": ["image-1.jpg"]}
  }]
}

MultiPath3D는 InspectMap 전용 경로 표현입니다. 면형 손상의 경계를 포함할 수 있지만 GeoJSON Polygon의 링·면 위상 규칙을 보장하지 않습니다. 균열 두께 p90은 영상 탐지의 추정값이며 현장 실측값이 아닙니다.
